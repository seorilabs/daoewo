# ADR 0004: 프리미엄 콘텐츠는 서버 권위 창으로 전달한다

- 상태: Accepted
- 날짜: 2026-07-12

## 결정

Free 덱 본문은 오프라인 번들/캐시를 허용한다. Pro 덱의 전체 본문은 클라이언트가 직접 읽을 수 없고, 인증·App Check를 통과한 Functions가 오늘 배정분과 도래 복습만 24시간 창으로 반환한다.

덱 본문은 기본 200장 단위 불변 JSON 청크로 Cloud Storage에 저장한다. Firestore에는 카탈로그 메타와 유저별 압축 progress만 둔다. Functions는 `(deckId, version, chunkIndex)`로 필요한 청크를 직접 계산해 읽고 웜 인스턴스에서 캐시한다.

## 남용 방지 기본값

- Free: 일일 60장, 활성 덱 1개
- Pro: 제품 사용량 제한 없음
- Pro abuse soft-cap: 사용자 600 고유 카드/일, 기기 300 고유 카드/일
- 목표 리셋 cooldown: 덱별 24시간
- 다음 창: 현재 창 답변 제출과 스케줄 날짜 도래 후에만 발급

soft-cap은 정상 학습 기능 제한이 아니라 비정상 추출을 탐지·스로틀하기 위한 서버 운영값이며 Remote Config/서버 설정으로 조정한다.

## 결과

완전 DRM은 보장하지 않는다. 화면에 표시된 한 장은 캡처될 수 있지만, 전체·미래분 bulk export와 목표 churn을 통한 대량 추출을 정상 일일 처리량 근방으로 제한하고 감사 로그를 남길 수 있다.
